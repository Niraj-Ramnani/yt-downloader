# YouTube Downloader

A modern and vibrant web application that converts YouTube video URLs into downloadable MP3 links using the RapidAPI service. Built with Node.js, Express, and EJS, this app features a responsive design with smooth transitions and an attractive UI.

## Features
- Convert YouTube videos to downloadable MP3 links.
- User-friendly interface with real-time feedback.
- Responsive design for desktop and mobile devices.
- Animated transitions for an engaging user experience.
- Deployed on Render for public access.

## Technologies Used
- **Backend**: Node.js, Express
- **Templating**: EJS
- **API**: RapidAPI (YouTube Search and Download MP3)
- **Styling**: CSS with custom animations
- **Hosting**: Render

## Prerequisites
- Node.js (v14 or higher recommended)
- npm (Node Package Manager)
- A RapidAPI key for the YouTube MP3 conversion API
